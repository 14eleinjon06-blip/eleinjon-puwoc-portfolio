# Eleinjon D. Puwoc — Portfolio

A responsive personal portfolio website built with HTML, CSS, and JavaScript.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel
1. Import the repository `14eleinjon06-blip/eleinjon-puwoc-portfolio` into Vercel (or open the existing Vercel project).
2. In **Settings → Build and Deployment**, set **Root Directory** to `new-profile-portfolio`.
3. Set Framework Preset to **Other**.
4. Leave Build Command and Output Directory empty; this is a static HTML website.
5. Redeploy.

This folder is separate from the existing portfolio files and does not replace them.
